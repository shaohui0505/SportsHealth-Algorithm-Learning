# 第六阶段：企业级项目

> 目标：完成接近真实企业需求的完整项目

## 为什么学

企业需要的不是跑通 demo，而是能落地的完整系统。本阶段整合前五个阶段的能力。

## 项目列表

### 项目 1：运动分类
- **输入**：100Hz 三轴加速度 + 三轴陀螺仪
- **输出**：Walking / Running / Cycling / Standing / Sitting
- **模型**：CNN + LSTM

### 项目 2：心率预测
- **输入**：PPG、运动强度、年龄、BMI
- **输出**：Heart Rate

### 项目 3：疲劳检测
- **输入**：HRV、睡眠、训练负荷
- **输出**：Recovery Score

### 项目 4：运动处方推荐
- **输入**：年龄、BMI、VO₂max、HRV、睡眠、训练历史
- **输出**：个性化训练计划

### 项目 5：论文复现
- 复现近年来运动健康领域的经典论文

## 目录结构

每个项目独立一个子目录，包含：
- `data/` — 数据（原始 + 处理后）
- `src/` — 源码
- `notebooks/` — 实验 Notebook
- `models/` — 训练好的模型
- `reports/` — 实验报告与图表
