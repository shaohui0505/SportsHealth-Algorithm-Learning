# 第三阶段：机器学习

> 目标：用监督学习 / 无监督学习解决运动健康问题

## 为什么学

运动健康中的预测问题（VO₂max、疾病风险、卡路里）大多是经典机器学习问题。

## 学习内容

### 基础范式
- 监督学习（分类 / 回归）
- 无监督学习（聚类 / 降维）
- 训练集 / 验证集 / 测试集划分
- 过拟合与正则化

### 核心模型
| 模型 | 适用场景 |
|---|---|
| Linear Regression | 连续值预测（如卡路里） |
| Logistic Regression | 二分类（如高风险人群） |
| SVM | 小样本分类 |
| Decision Tree | 可解释分类 |
| Random Forest | 集成学习，泛化强 |
| XGBoost | 表格数据最强模型之一 |

### 工具
- Scikit-learn

## 阶段项目

1. **VO₂max 预测**：根据年龄、BMI、运动时间、静息心率、睡眠时间预测 VO₂max
2. **高风险人群分类**：预测是否属于运动健康高风险人群
