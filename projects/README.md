## 项目模板

每个项目建议使用以下结构：

```
SportsHealth-XXX-项目名/
├── README.md           # 项目说明：目标、数据、方法、结果
├── data/
│   ├── raw/            # 原始数据（不提交大文件，用 .gitignore 排除）
│   └── processed/      # 处理后的数据
├── src/                # 源码（数据处理、模型、训练、评估）
├── notebooks/          # 实验 Notebook
├── models/             # 训练好的模型权重
└── reports/
    ├── figures/        # 图表（必须由真实结果生成）
    └── experiment_log.md  # 实验记录（超参数、seed、指标）
```

## 项目原则

1. **数据真实** — 来自真实采集或公开数据集，不用随机假数据
2. **结果可追溯** — 每个图表、指标都能找到对应的代码和数据
3. **实验可复现** — 记录超参数、随机种子、数据划分
4. **绘图只读** — 绘图脚本只读取已落盘的结果文件，不生成数值
