# 第二阶段：数学基础（只学算法需要的）

> 目标：掌握运动健康算法所需的核心数学概念，不做数学研究

## 为什么学

不需要学完整高数，只需掌握算法直接用到的部分。

## 学习内容

### 统计学（`statistics/`）
- 平均值、标准差、方差
- 异常值检测
- 相关系数、P 值
- **应用**：运动后心率是否显著下降？

### 线性代数（`linear-algebra/`）
- 矩阵、向量、矩阵乘法
- **应用**：所有神经网络本质都是矩阵运算

### 概率（`probability/`）
- 贝叶斯、高斯分布、概率密度
- **应用**：异常检测大量使用

### 优化（`optimization/`）
- 梯度下降、Loss、学习率
- **应用**：所有 AI 训练的核心
