# 第一阶段：编程基础 + 数据分析

> 目标：从不会写代码 → 能独立分析数据

## 为什么学

算法工程师 80% 的时间都在处理数据。Python + 数据分析是一切的起点。

## 学习内容

### Python 基础
- 变量、循环、函数、类
- 文件读写、异常处理

### 数据分析三件套
- **NumPy** — 数组运算、向量化操作
- **Pandas** — DataFrame 数据清洗与分析
- **Matplotlib** — 数据可视化

### 工具
- Jupyter Notebook
- Git 基础（clone / commit / push）

## 企业真实工作量

★★★★★ — 数据处理占据算法工程师绝大部分时间。
