## 信号处理（非常重要）

运动健康几乎离不开信号处理：

```
FFT（快速傅里叶变换）
Butterworth Filter（巴特沃斯滤波器）
Median Filter（中值滤波）
Kalman Filter（卡尔曼滤波）
Wavelet（小波变换）
Peak Detection（峰值检测）
Noise Removal（去噪）
```

**典型应用**：PPG 信号降噪、心率峰值检测、运动伪影去除。
